# Quickstart: Rede de Relações

1. Open `/c/:slug/relacoes` — chips in column with line samples; no type legend on stage.
2. Greyscale/check: types in same family differ by stroke.
3. Hover edge → label; no mass labels.
4. Tab between nodes; Enter selects.
5. Detail without portrait/description → no big placeholder / no «Sem descrição.»
6. `npm run lint:tokens && npm run test:contrast`
