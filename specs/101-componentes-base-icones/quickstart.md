# Quickstart: Componentes base e ícones

1. `cd frontend && npm install && npm run dev`
2. Abrir `/__styleguide` — ver Button, Dialog, Drawer, Toast, ConfirmDialog demos.
3. Fluxo excluir (NPC/local/arco/vínculo/nó): ConfirmDialog app, não browser; Esc cancela e devolve foco.
4. Upload falhado: Toast, não `alert`.
5. `rg 'window\.(confirm|alert)' frontend/src` → zero hits.
6. CHANGELOG menciona Tabler + delta de bundle aproximado.
